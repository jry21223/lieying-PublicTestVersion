## 🎉 零配置，解压即用！

本便携版内置了 Go 和 Node.js 运行时，无需安装任何依赖，解压后即可使用！

---

## 📦 目录结构

```
lieying-portable/
├── runtime/              # 运行时环境
│   ├── go/              # Go 1.21+
│   └── node/            # Node.js 18+
├── core/                # 猎影后端
├── frontend/            # 猎影前端
├── start.bat            # 一键启动脚本
└── README.txt           # 快速开始
```

---

## 🚀 快速开始

### Windows 用户

1. **解压文件**
   - 将 `lieying-portable.zip` 解压到任意目录
   - 例如：`D:\lieying-portable\`

2. **双击启动**
   - 进入解压后的文件夹
   - 双击 `start.bat`
   - 等待自动启动完成

3. **访问界面**
   - 浏览器会自动打开 `http://localhost:5173`
   - 或手动访问该地址

### 就是这么简单！🎊

## 📋 系统要求

- **操作系统**: Windows 10/11 (64位)
- **内存**: 4GB+
- **磁盘空间**: 2GB+
- **网络**: 可选（支持离线模式）

---

## 🔧 手动配置（可选）

### 修改端口

编辑 `start.bat`，修改以下行：

```batch
REM 后端端口（默认3000）
set BACKEND_PORT=3000

REM 前端端口（默认5173）
set FRONTEND_PORT=5173
```

### 离线模式

编辑 `core\internal\config\config.yaml`：

```yaml
network:
  mode: offline
```

## ❓ 常见问题

### Q1: 提示缺少 DLL 文件

**解决**: 安装 Visual C++ Redistributable
- 下载：https://aka.ms/vs/17/release/vc_redist.x64.exe
- 安装后重启电脑

### Q2: 启动后无法访问

**解决**: 检查端口是否被占用
1. 修改 `start.bat` 中的端口号
2. 重新启动

### Q3: 如何更新版本

**解决**: 
1. 备份 `core\` 和 `frontend\` 目录（保留你的数据）
2. 下载新版本便携版
3. 解压覆盖
4. 恢复备份的数据

### Q4: 如何完全卸载

**解决**: 直接删除整个文件夹即可，不会在系统中留下任何残留
