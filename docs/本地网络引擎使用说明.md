# 猎影本地网络引擎 - 使用指南

## 概述

猎影本地网络引擎确保所有渗透测试流量直接从用户本机发出，无需依赖后端服务器中转。所有扫描工具（Nuclei、Amass、Nmap等）在本地执行，数据存储在本地数据库。

## 架构设计

### 核心组件

1. **网络引擎** (`pkg/network/engine.go`)
   - HTTP/HTTPS请求（支持代理、自定义Header）
   - TCP/UDP端口扫描
   - DNS解析
   - 并发控制、请求限制

2. **限流器** (`pkg/network/ratelimit.go`)
   - 令牌桶限流算法
   - 自适应QPS调整
   - 按目标限流

3. **请求日志记录器** (`pkg/network/request_logger.go`)
   - 全量请求/响应记录
   - JSON/CSV导出
   - 按模块/目标筛选

4. **工具执行器** (`pkg/executor/tool.go`)
   - 外部工具统一封装
   - 代理环境变量传递
   - 超时控制、可中断

5. **任务调度器** (`pkg/scheduler/scheduler.go`)
   - 并发任务执行
   - 任务暂停/恢复/取消
   - Worker pool模式

6. **任务管理器** (`internal/service/task_manager.go`)
   - 信息收集任务调度
   - 漏洞扫描任务调度
   - 任务持久化

## 快速开始

### 1. 配置文件

编辑 `config.yaml`:

```yaml
network:
  proxy:
    enabled: false
    type: "http"
    host: "127.0.0.1"
    port: 8080
    username: ""
    password: ""

  concurrency: 10
  qps: 50
  timeout: 30
  retries: 3
  user_agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
  follow_redirects: true
  skip_tls_verify: false

tools:
  nuclei:
    path: "nuclei"
  amass:
    path: "amass"
  subfinder:
    path: "subfinder"
  nmap:
    path: "nmap"
```

### 2. 安装扫描工具

```bash
# Nuclei
go install -v github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest

# Subfinder
go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest

# Amass
go install -v github.com/owasp-amass/amass/v4/...@master

# Nmap (Windows)
# 下载安装: https://nmap.org/download.html
```

### 3. 启动猎影

```bash
# 启动后端
cd core
./lieying.exe server

# 启动前端（另一个终端）
cd frontend
npm run dev
```

访问 `http://localhost:5173` 开始使用。

## 功能模块

### 网络设置

访问左侧菜单「网络设置」：

1. **代理配置**
   - HTTP/HTTPS/SOCKS5代理
   - 支持认证
   - 连通性测试

2. **扫描策略**
   - 并发数 (1-50)
   - QPS限制
   - 超时时间
   - User-Agent池
   - 跟随重定向
   - TLS验证跳过

3. **保存配置后立即生效**

### 主动扫描

访问「主动扫描」：

1. **创建扫描任务**
   - 输入任务名称
   - 输入目标（URL或IP）
   - 选择扫描类型：
     - Web扫描：HTTP请求
     - 端口扫描：TCP端口检测
     - 漏洞扫描：Nuclei模板扫描

2. **查看结果**
   - 实时进度更新
   - 状态显示（等待中/运行中/已完成）
   - 点击任务查看详细结果

### 请求历史

访问「请求历史」：

1. **查看所有网络请求**
   - 时间、目标、方法、状态、耗时
   - 按模块/目标/方法筛选
   - 搜索功能

2. **详情查看**
   - 请求头/请求体
   - 响应头/响应体
   - 重放请求

3. **导出功能**
   - JSON格式导出
   - CSV格式导出

### 代理池

访问「代理池」：

1. **管理代理列表**
   - 添加代理（HTTP/HTTPS/SOCKS5）
   - 编辑/删除代理
   - 启用/禁用代理

2. **代理测试**
   - 一键测试代理连通性
   - 显示延迟

3. **批量导入/导出**
   - 支持JSON格式
   - 支持TXT格式 (host:port)

### 信息收集

1. **子域名枚举**
   - Subfinder集成

2. **端口扫描**
   - Nmap集成

3. **目录爆破**

## 故障排除

### 工具无法找到

```
检查工具是否在PATH中:
$ which nuclei
$ which subfinder

或在config.yaml中指定完整路径:
tools:
  nuclei:
    path: "/usr/local/bin/nuclei"
```

### 代理连接失败

```
1. 测试代理地址是否正确
2. 检查代理认证信息
3. 验证代理是否允许目标端口
4. 检查防火墙规则
```

### 扫描无结果

```
1. 检查目标是否在线
2. 确认网络连接正常
3. 降低扫描强度
4. 查看请求历史分析
```

### 性能问题

```
1. 减少并发数
2. 降低QPS限制
3. 增加超时时间
4. 关闭不必要的功能
```

## 开发指南

### 扩展网络引擎

```go
// 创建自定义HTTP客户端
engine, err := network.NewNetworkEngine(&network.EngineConfig{
    Proxy: &network.ProxyConfig{
        Enabled: true,
        Type: "http",
        Host: "127.0.0.1",
        Port: 8080,
    },
    QPS: 50,
})

// 发送请求
resp, err := engine.Get(context.Background(), "https://example.com")
```

### 集成新工具

```go
// 使用工具执行器
exec := executor.NewToolExecutor("mytool", []string{"-target", target})
exec.SetProxy(proxyConfig)
result, err := exec.Run(context.Background())
```

### 添加新任务类型

```go
// 创建任务
task, err := taskManager.CreateTask(
    service.TaskTypeInfoCollect,
    "example.com",
    map[string]interface{}{"option": "value"},
)

// 查询状态
stats := taskManager.GetStats()
```
